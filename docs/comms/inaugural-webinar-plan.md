## Agenda

### 09:00 — Opening & Welcome (30 min)
- **09:00** Welcome remarks — COMM-ONNECT / Platform Director
- **09:10** Opening address — BMKG representative (invited speaker)
- **09:20** Context setting: Indonesia's climate monitoring gap and the platform's mandate

### 09:30 — Platform Overview (45 min)
- **09:30** Architecture overview: NASA satellite constellation + Indonesian ground networks
  - Speaker: CLIMATE-OS / Platform Architecture lead
  - Key points: 5 NASA missions, BMKG/KLHK/LAPAN integration, PP 71/2019 compliance, CC-BY 4.0 open data
- **09:50** Live platform demonstration (TERRA-VISION dashboard walkthrough)
  - Deforestation alert map (Kalimantan live)
  - Air quality dashboard (Jakarta + Sumatera)
  - Flood early warning (Ciliwung basin)
  - Climate bulletin generation demo

### 10:15 — Agency Partnership Briefings (30 min)
- **10:15** BMKG Partnership: Data integration scope + co-branded weather alert products
- **10:22** KLHK Partnership: Deforestation alerts + AQI monitoring program
- **10:29** LAPAN/BRIN Partnership: SAR-optical fusion project introduction

### 10:45 — Technical Deep-Dives (45 min)
*Split into three concurrent breakout rooms (virtual + in-person)*

| Room | Topic | Target Audience |
|---|---|---|
| Breakout A | API Access & Developer Integration | Researchers, IT teams |
| Breakout B | Deforestation & Land Cover Products | KLHK, GEOSPATIAL researchers |
| Breakout C | Flood Early Warning & Hydrology Products | BNPB, BMKG, BPBD |

### 11:30 — Plenary Q&A + Partnership Next Steps (20 min)
- Open Q&A with platform technical team
- Partnership MOUs: status update and signing ceremony preview (BMKG/KLHK/LAPAN)
- Roadmap preview: H2 2026 feature releases

### 11:50 — Closing & Networking (10 min)
- Closing remarks
- Platform access registration booth (in-person)
- Light refreshments (in-person)
