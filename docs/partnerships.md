# Partnership Framework

## Institutional Partners

### BMKG (Badan Meteorologi, Klimatologi, dan Geofisika)
- **Role**: Primary ground observation data provider + co-authorship on weather alert products
- **Data Shared**: AWS observations, rain gauge network, seasonal forecasts
- **Integration**: REST API + daily SFTP batch transfer
- **Contact Agent**: COMM-ONNECT
- **Status**: MOU under preparation

### KLHK (Kementerian Lingkungan Hidup dan Kehutanan)
- **Role**: Forest cover reference data + air quality monitoring network
- **Data Shared**: Annual land cover map, air quality index stations, deforestation ground truth
- **Integration**: KLHK Open Data API
- **Contact Agent**: COMM-ONNECT
- **Status**: Letter of Intent submitted

### LAPAN (Lembaga Penerbangan dan Antariksa Nasional)
- **Role**: Indonesian remote sensing data + satellite capacity coordination
- **Data Shared**: SPOT-7, SAR, Himawari-9 processed products
- **Integration**: LAPAN data portal API
- **Contact Agent**: COMM-ONNECT
- **Status**: Initial meetings completed

## Data Sharing Principles

1. Platform outputs remain open under CC-BY 4.0
2. Partner raw data usage governed by individual MOUs
3. Indonesian PP No. 71/2019 on data residency: all raw data stored on AWS ap-southeast-3 (Jakarta)
4. Joint publications acknowledge all contributing institutions

## Governance

- Quarterly joint steering committee (CLIMATE-OS chairs)
- Annual stakeholder workshop for platform roadmap input
- Monthly technical sync: DATA-FLOW + BMKG technical teams
